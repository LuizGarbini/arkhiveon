# PROTOTYPE - Ecos

Question: should Ecos be shaped primarily as a post-session workflow, an entity-memory panel, or a consequence web?

Frozen decision:

- Winning direction: frozen for now.
- Why: the screen is promising, but the feature needs deeper GM customization before it should move toward production.
- Pieces to keep in mind: the "living memory" framing, related state panels inside entities, and the visible consequence web.
- Current plan: do not expand this prototype in the next pass. The active product focus moved to visual control of characters and NPCs.

Original tested variants:

- `A` - Post-session workflow: creates Ecos from important session events.
- `B` - Entity memory: shows related Ecos inside NPCs, locations, factions, sessions, and lore.
- `C` - Living web: makes the consequence graph the signature view.
